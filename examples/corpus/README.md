# Демонстрационный корпус

Файлы в этом каталоге **синтетические**: они написаны для проверки конвейера и
не являются выдержками из реальных стандартов, книг или отчётов. Не используйте
их как техническую справку.

В реальной установке сюда попадает результат конвертации вашей библиотеки:
`literature/`, `standards/`, `datasheets/` — индекс A, `reports/` — индекс B,
`regulations/` — индекс C (см. док. 03, раздел 3.3).
