The LDPC submatrices (for FID = 0) are provided in three different file formats as attachments 
to LNIS AD1 Volume A, as listed in  Table 1. 
 
 
Table 1. LDPC Submatrices Electronic Files 
 
ZIP files for the LunaNet AFS FID=0 LDPC submatrix representations are provided in two 
different formats ( Table 1 ID#1 and ID#2): 
• A format containing indices (“_ind.zip”) provided in row, column pairs that are separated 
by new lines. Each index represents a location where a value of “1” can be found in the 
submatrix. 
• A format containing the full matrix (“_mat.zip”), with entire matrix captured in a CSV file. 
  
Basic README files are included in both ZIP folders. The text for each README file is included 
below for convenience.
