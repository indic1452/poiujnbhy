# Первоисточники

Оригиналы документов, по которым построены таблицы кодов и режимов: руководства модемов, даташиты, патенты, стандарты, открытый код. Папка идёт вместе с репозиторием на изолированную машину, в пакет (колесо) не входит. У каждого файла — откуда, когда скачан, sha256 и что из него взято. Каждое семейство пишет свой раздел.

## tpc

Первоисточники по ТКБ (турбокод блочный, TPC/BTC/eTPC): даташиты AHA (Comtech AHA), руководства модемов Comtech, Radyne, Datum, Paradise, вклады IEEE 802.16 с текстом разделов BTC, патенты eTPC, White Paper Advantech, ITU-R M.584 (БЧХ (32,21)). Скачано 2026-09-29…30 через открытую сеть; файлов больше 40 МБ нет (самый большой — SLM-5650A, 14 МБ). Страницы — по номеру страницы PDF (в скобках — номер страницы документа). Рядом с PDF и HTML лежит извлечённый текст (`*.pdf.txt`, `*.txt`) — для поиска; в таблице не повторяется. Руководства модемов скачаны со сторонних зеркал (newerasystems, manualzilla/manualsbase на archive.org, mcbia и др.): распространять ли их вне отдела, решает отдел.

Сверка всех таблиц (многочлены, AHA4501 Table 4, AHA4524, Table 192/OFDMA 802.16, примеры укорочения, скорости Comtech) — `python3 istochniki/tpc/proverki/sverka_tpc.py` (assert; «все проверки прошли»); те же таблицы сверяются с каталогом анализатора в `tests/test_potok_tpc_rezhimy.py`, а класс `СверкаСФайламиИсточников` там же разбирает текст самих файлов (`*.pdf.txt`: AHA4501 Table 4, AHA4524 Table 1, 802.16 Table 192 и OFDMA, Table 1 многочленов, цитаты Radyne/Comtech/Advantech) и проверяет, что каждый файл, на который ссылается каталог, лежит здесь. Каталог режимов в коде — `src/reportgen/potok/tpc_rezhimy.py` (у каждого режима — файл и страница).

Не найдено и не положено (только ссылка): Comtech «The Case for Turbo Product Coding in Satellite Communications» (comtechefdata.com переехал; копия только на web.archive.org — недоступен из этой сети); IESS-315 (intelsat.com — 404, копия только на web.archive.org); полные даташиты AHA4540/AHA4541 (alldatasheet, chipfind — 403); iDirect TRG/LBA (scribd, pdfcoffee — 403); полный текст IEEE 802.16-2004 (платный; взяты вклады с текстом разделов). Дамп прошивки Paradise P300 (archive.org, `P300-firmware-v3.64`) не скачан. Руководство Paradise Quantum/Evolution с перечнем режимов TPC Paradise (0.493, 0.666, 0.789, 7/8, 0.929) лежит у семейства ldpc: `istochniki/ldpc/paradise/Quantum_Evolution_Handbook_3.0.17_skybrokers.pdf`, стр. 59, 62–64.
