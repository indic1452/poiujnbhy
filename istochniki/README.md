# Первоисточники

Оригиналы документов, по которым построены таблицы кодов и режимов: руководства модемов, даташиты, патенты, стандарты, открытый код. Папка идёт вместе с репозиторием на изолированную машину, в пакет (колесо) не входит. У каждого файла — откуда, когда скачан, sha256 и что из него взято. Каждое семейство пишет свой раздел.

## ldpc

Первоисточники по кодам LDPC (встроенные семейства, режимы модемов, закрытые семейства). Скачано 2026-09-29…30 через открытую сеть (документы рабочих групп IEEE 802.11 — mentor.ieee.org, открытые); файлов больше 40 МБ нет. Страницы — по номеру страницы PDF. Руководства и даташиты Comtech, Paradise, Datum скачаны со сторонних зеркал (sky-brokers, ai-sat и др.; даташит Q-Flex — cherry-white.co.uk): распространять ли их вне отдела, решает отдел. Сверки и построение таблиц в `ldpc/proverki/` (запуск из корня репозитория: `python3 istochniki/ldpc/proverki/sverka_fldpc.py`, `postroit_docsis.py` и т. д.) проходят на этих файлах; `postroit_docsis.py` читает матрицы DOCSIS 3.1 с картинок стр. 60 (шаблоны цифр) и сверяет с текстом IEEE 802.3bn.

Не положено (ссылка только): 802.11ad-phy-sim (github.com/jirimilos/802.11ad-phy-sim, f986bfc) — без лицензии; третий голос за матрицы 802.11ad (LDPC_matrix.m, «case 672», «case 624»): `postroit_80211ad.py ПУТЬ` сверяет с ним, если передать путь к копии (журнал `postroit_80211ad.log` — со сверкой); ldpc-decoder-rtl (github.com/AspiringPianist/ldpc-decoder-rtl) — без лицензии, те же матрицы 802.11ad в rtl_pipe/ldpc_tables.svh; база кодов RPTU (rptu.de/channel-codes, alist 802.11ad) — через сеть недоступна (сброс соединения); AFF3CT configuration_files (github.com/aff3ct/configuration_files, d8441dd) — без файла лицензии, из него взяты прежние встроенные коды (5G NR и др.), а dec/LDPC/WIMAX_480_576.alist — третий голос за 50 в блоке (3, 0) WiMAX 5/6 (сдвиг 12 = ⌊50·24/96⌋; см. proverki/postroit_wimax.py); стандарты IEEE 802.11/802.16/802.3an — платные; ARIB STD-B44, GB 20600 — недоступны.

## ldpc_kitay

Первоисточники по кодам LDPC КНР (ABS-S, CMMB, DTMB, BeiDou; китайская редакция DVB-S2). Скачано 2026-09-30 через открытую сеть; файлов больше 40 МБ нет. Сборка `src/reportgen/potok/data/ldpc_kitay.json` — `python3 istochniki/ldpc_kitay/proverki/sborka_kitay.py` (читает только эти файлы; assert по каждому коду; журнал — `proverki/sborka_kitay.log`).

Что такое «CASC LDPC». Кода с таким именем в открытых источниках нет. CASC (中国航天科技集团) — владелец спутников вещания и связи «Чжунсин» (ChinaSat, через China Satcom) и головной разработчик космической связи КНР (CAST, 5-я академия; «Спейс Стар Текнолоджи» / 航天恒星科技 — разработчик модемов). По открытым документам с CASC связаны три семейства LDPC: (1) ABS-S — стандарт спутникового ТВ-вещания КНР на спутниках «Чжунсин-9» и далее (коды — ниже); (2) GY/T 338-2020 — китайская редакция DVB-S2 (ETSI EN 302 307-1 v1.4.1), среди разработчиков — 航天恒星科技有限公司; коды LDPC те же, что DVB-S2 (в проекте уже встроены); (3) GB/T 39348-2020 «遥测同步与信道编码» — китайская редакция CCSDS 131.0 (разработчики — 中国航天标准化研究所, 北京空间飞行器总体设计部 CAST); коды — CCSDS C2 (8176, 7154) и AR4JA; текст стандарта открыт только для чтения на сайте openstd.samr.gov.cn, файлом не получен. Скорее всего «CASC LDPC» в перечне аналитика — одно из этих семейств (чаще всего ABS-S или CCSDS по GB/T 39348).
