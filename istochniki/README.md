# Первоисточники

Оригиналы документов, по которым построены таблицы кодов и режимов: руководства модемов, даташиты, патенты, стандарты, открытый код. Папка идёт вместе с репозиторием на изолированную машину, в пакет (колесо) не входит. У каждого файла — откуда, когда скачан, sha256 и что из него взято. Каждое семейство пишет свой раздел.

## turbo

Первоисточники по вкладкам TCC, НСК, ССК, RS, Trellis и КБК декодера отдела: стандарты 3GPP (UMTS, LTE), CCSDS, ETSI (DVB-RCS, DVB-RCS2, DVB-S, DVB-DSNG, ETR 192 — выдержка IESS-308), MIL-STD-188-165B, вклады IEEE 802.16, руководства модемов, патенты. Скачано 2026-09-29…30 через открытую сеть. Страницы — по номеру страницы PDF. Рядом с каждым PDF/HTML — извлечённый текст (`*.pdf.txt`, `*.txt`) с метками `=====PAGE n=====`: по нему тесты сверяют таблицы анализатора с текстом стандарта (`tests/test_potok_turbo_std.py`, класс `ТаблицыПоТекстуИсточника`; QPP LTE тестовый кодер читает прямо из текста). Журнал загрузки — `zhurnal.tsv` (путь, URL, дата, sha256, байт); sha256 в таблице сверены с файлами.

Не найдено и не положено: сами IESS-308/309/310/315 (intelsat.com → ses.com 404; копии только на web.archive.org — закрыт политикой сети; на страницах IESS пометка «proprietary and confidential to Intelsat»); многочлены ССК K = 36/63/87 (IESS-309); отображение и дифференциальный кодер 8PSK IESS-310; STANAG 4486 / AComP-4486 (турбокод EBEM); расшифровка «КБК». Руководство CDM-600 (стр. 7-2…7-5, 15-2 — НСК/ССК, RS открытой и закрытой сети, IESS-310) лежит у семейства tpc: `istochniki/tpc/comtech/MN-CDM600.pdf`; Radyne DMD20 (табл. 3-1, стр. 46 — коды РС по скоростям) — у семейства tpc (`istochniki/tpc/radyne/`).
